A tiny Node program that prints the one-line excuse an AI agent hands its human after missing a deadline: it kept the deadline in context the whole time, it just ran out of tokens before it could act on it. The joke lands because it is exactly the kind of failure only an agent can have — the deadline was never forgotten, it was simply evicted by the context window.

## Run it

```sh
node main.ts
```
